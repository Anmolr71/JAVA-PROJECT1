# Experiment 06 – Java Servlets

## Objective
To develop a web application using Java Servlets.

## Concepts Covered
- Servlet lifecycle
- HTTP requests and responses
- Request handling
- Web application deployment

## Features
- Server-side request processing
- Dynamic web responses

## Technologies Used
- Java
- Java Servlets
- Apache Tomcat

## How to Run
1. Configure Apache Tomcat.
2. Deploy the servlet application.
3. Start the server.
4. Open the application in a web browser.
