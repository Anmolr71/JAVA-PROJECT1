# Experiment 03 – Calculator using MVC

## Objective
To develop a calculator application using the Model-View-Controller (MVC) design pattern in Java.

## Concepts Covered
- Model-View-Controller (MVC) architecture
- Java Swing GUI
- Event handling
- Separation of concerns
- Basic arithmetic operations

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User-friendly graphical interface

## Technologies Used
- Java
- Java Swing
- MVC Design Pattern

## How to Run
1. Download or clone this project.
2. Open it in an IDE such as VS Code, Eclipse, or IntelliJ IDEA.
3. Compile and run the main Java class.
