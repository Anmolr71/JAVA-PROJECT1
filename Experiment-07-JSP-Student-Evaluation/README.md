# Experiment 07 – JSP Student Evaluation

## Objective
To develop a student evaluation web application using JavaServer Pages (JSP).

## Concepts Covered
- JSP syntax
- Server-side processing
- HTML forms
- Dynamic web content
- Java web application development

## Features
- Student information input
- Evaluation data processing
- Dynamic result display

## Technologies Used
- Java
- JSP
- Apache Tomcat

## How to Run
1. Configure Apache Tomcat.
2. Deploy the JSP project.
3. Start the server.
4. Open the application in a web browser.
